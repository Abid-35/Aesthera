# Aesthera - Fashion Landing Page 👗✨  

Aesthera is a modern, elegant, and responsive fashion landing page built using **HTML5** and **CSS3**.  
It showcases a collection of outfits with a clean layout and smooth user experience.  

## 🌟 Features  

- **Working Navigation Links**  
  - Smooth scroll to different sections: Home, Collections, About, and Contact.  
  - Sticky navigation bar that stays visible while scrolling.  

- **Hero Section**  
  - Tagline: *“Elegance meets only with Aesthera”*.  
  - Call-to-action button that links to collections.  

- **Features Section**  
  - Six highlight boxes explaining why to choose Aesthera.  
  - Hover effects and responsive flex layout.  

- **Collections Gallery**  
  - Grid of fashion images.  
  - Auto-adjusting grid using CSS.  
  - Smooth hover zoom effect on images.  

- **About Section**  
  - Brief brand story and vision.  

- **Footer**  
  - Contact information (email, Instagram, phone).  
  - Copyright notice.  

## 📱 Responsiveness  

The page is fully responsive across **desktop, tablet, and mobile**:  

- **Desktop (≥1200px)**:  
  - Wide multi-column layout for features and collections.  
  - Navigation links aligned horizontally.  

- **Tablet (768px – 1199px)**:  
  - Feature boxes arranged in rows (thanks to media query).  
  - Collections grid adapts to 2–3 images per row.  

- **Mobile (<768px)**:  
  - Navigation links wrap naturally into multiple lines.  
  - Feature boxes stack vertically for easy readability.  
  - Collections grid shows 1–2 images per row.  

## 🛠️ Tech Stack  

- **HTML5** – semantic structure  
- **CSS3** – layout, responsiveness, and styling
